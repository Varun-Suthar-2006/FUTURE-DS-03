# Marketing Funnel Analysis (Bank Dataset)

## Objective
To analyze marketing campaign data and understand conversion patterns.

## Tools Used
Python, Pandas, Matplotlib, Seaborn

## Key Work Done
- Data cleaning and preprocessing
- Funnel analysis (lead to customer conversion)
- Visualization of customer behavior
- Segment-wise performance analysis

## Key Insights
- Conversion rate calculated successfully
- Job and contact type affect conversion
- Duration of call improves conversion probability

## Outcome
Identified key drop-off points and factors influencing customer conversion.
